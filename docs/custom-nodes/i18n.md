# ComfyUI Custom Nodes i18n Support

ComfyUI enables multi-language support for custom nodes through a structured localization system. The platform currently supports nine languages including English, Simplified and Traditional Chinese, French, Korean, Russian, Spanish, Japanese, and Arabic.

## Supported Languages

| Language | Code |
|----------|------|
| English | en |
| Simplified Chinese | zh |
| Traditional Chinese | zh-TW |
| French | fr |
| Korean | ko |
| Russian | ru |
| Spanish | es |
| Japanese | ja |
| Arabic | ar |

## Implementation Structure

Developers create a `locales` folder within their custom node directory, organizing translation files by language code. English serves as the recommended base language, with subdirectories for each supported language containing JSON translation files.

```
custom_nodes/
  YourCustomNode/
    __init__.py
    locales/
      en/
        nodeDefs.json
        main.json
        settings.json
      zh/
        nodeDefs.json
        main.json
        settings.json
      fr/
        nodeDefs.json
        main.json
        settings.json
```

## Key Translation Files

### nodeDefs.json

Handles node definitions, including display names, descriptions, input/output labels, and tooltips. The file structure maps each node class to its localized metadata, with outputs referenced by index number rather than custom names.

```json
{
  "YourNodeClass": {
    "display_name": "Your Node Display Name",
    "description": "Description of what your node does",
    "inputs": {
      "input_name": {
        "name": "Input Display Name",
        "tooltip": "Tooltip for this input"
      }
    },
    "outputs": {
      "0": {
        "name": "Output Display Name",
        "tooltip": "Tooltip for this output"
      }
    }
  }
}
```

### main.json

Provides general translation content and settings category labels.

```json
{
  "category_label": "Translated Category Name",
  "general_text": "Translated general text"
}
```

### settings.json

Translates menu settings and interface elements.

```json
{
  "YourNodeName_SettingName": {
    "name": "Setting Display Name",
    "tooltip": "Setting tooltip description"
  }
}
```

## Settings Translation

Settings identifiers use dot notation in code (e.g., `I18nDemo.EnableDebugMode`) but require underscore conversion in translation keys (`I18nDemo_EnableDebugMode`). This applies to setting names, tooltips, and option values.

### Example

In your Python code:
```python
setting_id = "I18nDemo.EnableDebugMode"
```

In your translation file (`settings.json`):
```json
{
  "I18nDemo_EnableDebugMode": {
    "name": "Enable Debug Mode",
    "tooltip": "Enables additional debug logging"
  }
}
```

## Example Implementation

A working example demonstrating these practices with a text processing node is available in the [ComfyUI-i18n-demo repository](https://github.com/comfyui-wiki/ComfyUI-i18n-demo).

## Best Practices

1. **Use English as the base language** - Start with English translations and add other languages as needed.

2. **Organize by language code** - Keep translation files in subdirectories named after the language code.

3. **Reference outputs by index** - In `nodeDefs.json`, outputs are referenced by their index number (0, 1, 2, etc.) rather than custom names.

4. **Convert dots to underscores** - When translating settings, replace dots (`.`) with underscores (`_`) in the translation keys.

5. **Include tooltips** - Provide translated tooltips to improve user experience across all supported languages.
