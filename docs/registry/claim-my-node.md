# Claim My Node - ComfyUI Documentation

## Overview

The **Claim My Node** feature enables developers to take ownership of custom nodes in the ComfyUI Registry. This system provides "security and accountability within the community" by restricting management rights to authorized authors.

## Unclaimed Nodes Explained

During the migration from ComfyUI Manager to the Comfy Registry, many legacy custom nodes now appear as unclaimed. These nodes:

- Were originally in the ComfyUI Manager legacy system
- Have been migrated to meet current registry standards
- Await author claims for proper ownership control

The system facilitates "a smooth transition from the legacy system to the new registry standard while maintaining proper ownership and control."

## Claiming Process

The process involves three main stages:

1. **Navigate & Create Publisher**: Visit your unclaimed node page and select "Claim my node!" You'll need a publisher account if you don't already have one.

2. **Select Publisher**: Choose which publisher will own the node, which redirects you to the claim interface.

3. **Verification & Completion**: Review node information, authenticate via GitHub, verify admin repository access, and finalize the claim.

## Key Requirements

Claims require "admin access to the original repository." The system automatically validates GitHub permissions—only users with admin rights can successfully claim nodes.

## After Approval

Successful claims grant "full control over your node's management, including publish versions, updates meta, deprecation, and policy settings."
